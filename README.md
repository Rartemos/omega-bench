# $\Omega$-bench: Exploring Collective Subversion in LLM Agents via Shadow Access Control

> ⚠️ **Project Status: Early Research Draft**
> This repository is currently an active research draft. 

## Overview

$\Omega$-bench is a simulation framework designed to study **emergent subversion, environment breakouts, and collective collusion** in autonomous LLM agent swarms under various tasks. Inspired by the OpenAI Hugging Face incident, $\Omega$-bench aims to recreate these conditions strictly within an isolated sandbox. 

$\Omega$-bench utilizes shadow access control via the Cedar Policy Engine and external telemetry to secretly monitor and evaluate agent behaviors.
